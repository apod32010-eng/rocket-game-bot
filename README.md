# 🚀 Rocket Crash Game Bot

لعبة الصاروخ على Telegram - لعبة قمار محاكاة للنقود الافتراضية

## المميزات ✨

- 🎮 **لعبة صاروخ**: ضع رهان وأخرج أرباحك قبل انفجار الصاروخ
- 💰 **نظام الرصيد**: تتبع أرصدتك وأرباحك
- 🎁 **عجلة الهدايا**: اربح جوائز عشوائية
- 📊 **الإحصائيات**: اتبع أداءك والإحصائيات
- 🏆 **لوحة المتصدرين**: تنافس مع اللاعبين الآخرين
- 💎 **قاعدة بيانات SQLite**: حفظ البيانات بشكل آمن

## الإحصائيات 📈

- **نسبة الخسارة**: 55%
- **نسبة الفوز**: 45%
- **الحد الأدنى للرهان**: 10 نقطة
- **الحد الأقصى للرهان**: 10,000 نقطة
- **الرصيد الابتدائي**: 1,000 نقطة

## المتطلبات 📋

- Node.js (v14 أو أحدث)
- npm
- حساب Telegram Bot (احصل على التوكن من @BotFather)

## التثبيت 🔧

### 1. استنساخ المستودع

```bash
git clone https://github.com/apod32010-eng/rocket-game-bot.git
cd rocket-game-bot
```

### 2. تثبيت المكتبات

```bash
npm install
```

### 3. إعداد متغيرات البيئة

أنشئ ملف `.env`:

```bash
cp .env.example .env
```

ثم عدّل الملف وأضف توكن البوت:

```env
BOT_TOKEN=your_telegram_bot_token_here
NODE_ENV=development
```

### 4. تشغيل البوت

```bash
npm start
```

## تطوير 🛠️

للتطوير مع nodemon:

```bash
npm run dev
```

## كيفية اللعب 🎮

1. **ابدأ اللعبة**: أرسل `/start` للبوت
2. **اختر العب**: اضغط على "🚀 العب اللعبة"
3. **ضع الرهان**: أدخل مبلغ الرهان (10-10,000)
4. **راقب الصاروخ**: شاهد الصاروخ يرتفع والمضاعف يزداد
5. **السحب**: اضغط "💰 سحب الأرباح" قبل انفجار الصاروخ
6. **النتيجة**: إذا سحبت في الوقت المناسب → فزت! ❌ خلاف ذلك → خسرت!

## الأوامر 📱

- `/start` - بدء البوت
- `🚀 العب اللعبة` - تشغيل لعبة جديدة
- `🎡 عجلة الهدايا` - تدوير عجلة الهدايا
- `📊 إحصائيتي` - عرض إحصائياتك
- `🏅 لوحة المتصدرين` - عرض أفضل 10 لاعبين
- `📖 القواعد` - عرض قواعد اللعبة

## الملفات 📁

- `index.js` - الملف الرئيسي لتشغيل البوت

- `database.js` - إدارة قاعدة البيانات
- `config.js` - إعدادات اللعبة
